# EM4 ROS 驱动修复计划

目标：依据用户 v1.1 手册修复所给 ROS SDK，使真实 EM4.pcapng 能通过原驱动管线输出点云。

范围：只修改交付副本的 RSEM4 解码器和必要配置，不修改其他型号。保留 1084 字节非压缩包、旧版压缩包；支持抓包中的新版压缩块、1162 字节 DIFOP2、26 组有符号单字节 yaw 修正、4 面俯仰修正。默认等待有效标定，不使用外部网页适配器。

步骤：
1. 添加真实解码器回归测试，先验证新版 DIFOP2 和压缩输入在原版失败。
2. 在 RSEM4 专用文件实现有界压缩解码、标定、分片与组帧，验证固定格式和旧压缩回归。
3. 为 VLAN 129、自定义端口与点云话题提供在线/PCAP 配置和可传参启动入口。
4. 编译完整驱动核心，用原始 PCAPNG 经 libpcap、端口/VLAN 过滤、设备驱动和帧回调验证。
5. 交付干净 ROS 工作区压缩包、修改说明、运行说明与测试记录。当前主机没有 ROS，不把核心验证描述为 ROS 话题发布实测。

重点验证：截断压缩块、无效标定、分片错序、扫描面补偿、旧格式输入。

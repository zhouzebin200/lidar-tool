# 无授权 Windows x64 单文件发布结果

用户后续明确要求无需授权的单个 EXE，因此使用现有 `run.py` 入口，保留原授权版代码。

成品：`dist/unlicensed-x64/Lijian-LidarTool-Windows-x64.exe`（11,077,632 字节，约 10.6 MiB）。

SHA-256：`47c7c1371ba7204521bb2327ed46438ab7b1e3c11dd0678233165198b6579b97`

修复发布流程：缺少五厂商必需插件或 DLL 不是 x64 时停止；原生构建失败不再继续组包；旧一键入口转向完整的单文件构建。新增 Nuitka onefile 构建入口，显式嵌入 DLL、微软 vcruntime140/140_1、标定 .bin 和网页；管理员清单避免从解压的临时子程序重新提权。旧客户包未覆盖。

最终验证：

- Windows x64 Python 3.12.10，Nuitka 4.3；完整测试 95 项，OK。
- EXE PE 架构 x86-64，嵌有 requireAdministrator 清单。
- 成品内容审计及 SHA-256 校验通过。
- 仅 EXE 放到 `C:\ULV-SingleExe-Smoke`，不提供外部 plugins/web/corrections，移除 Python PATH/PYTHONHOME/PYTHONPATH 后运行通过。
- 无 license.key，五厂商插件全部加载，错误列表为空；首页、报告页面及两份脚本 HTTP 200。
- 合成 Velodyne PCAP：11 包、2 帧、末帧 1920 点、0 解码错误、0 丢包。不是物理雷达精度验收。
- 独立代码复核提出单文件提权问题，已通过管理员清单处理。

证据：`windows-x64-final-tests.txt`、`single-exe-smoke.json`、`build-unlicensed.log`。
构建完整 XML 报告保存在 `build/x64-review-source/compilation-report.xml`。

PD 为 ARM Windows，借助仿真运行 x64 软件。真实 x64 物理网卡、Npcap、VLAN、真实雷达型号和长时间运行尚待现场验证。Nuitka 自动运行库发现仍警告，但已显式嵌入 x64 vcruntime140.dll（120400 字节）及 vcruntime140_1.dll（49776 字节）；面向 Windows 10/11 自带 UCRT。

# 111.pcap 实包测试

输入：/Users/zzb/Desktop/111.pcap（不修改源文件）。
最终无授权单文件 EXE 在 PD Windows 中执行，离线测试退出码 0。

- 录包时长 3.24966 秒，20709 条捕获记录。
- Hesai 点云 UDP 20053 包，192.168.1.201:10000 → 255.255.255.255:2368，点云载荷 1118 字节；另有 650 个 99 字节 UDP 状态报文。
- 协议版本 4.3，当前识别标签 AT128。不能仅凭当前识别结果确认 AT128P 子型号。
- 解码输出 30 帧，末帧 141166 个非零点；解码错误 0、程序队列丢包 0、插件加载错误 0。这不证明抓包之前没有丢包。
- 独立使用同一组当前 DLL 提取帧时间戳：中位间隔 100.120064 ms，即约 9.988 Hz；范围 100.032～100.256 ms，符合 10 Hz。
- 末帧存在有效点的通道数 126；XYZ 均有限值。范围 X 0.573～13.622 m、Y -7.263～8.639 m、Z -2.500～2.646 m，没有出现全部 Z 为 0 的情况。
- 隔离缓存测试使用 AT128E2X.dat 标称标定，未获得该设备工厂标定。出点与帧率测试通过不等同于 AT128P 几何精度验收；精度应配合设备专属标定确认。

EXE 测试数据见 111-exe-offline.json；逐帧时间及点云统计见 111-frame-probe.json。

## 本次发布顺序

1. 在 Windows 中确认使用 x64 Python 3.10 或更高版本：`python -c "import platform,struct; print(platform.machine(),struct.calcsize('P')*8)"`。结果应为 AMD64、64；不能只检查操作系统位数。
2. 固定当前源码快照。将旧 `dist/customer` 整体归档到该目录之外，保留旧 ZIP 与哈希；正式构建会拒绝覆盖已有同名目录。
3. 若修改过原生代码，先按 `native/README.md` 重建 Windows x64 插件。核对 RoboSense、Hesai、Huawei L306、Velodyne、Seyond 五个 DLL 均存在，构建失败即停止。
4. 在 Windows 构建环境安装 README 指定依赖，执行 `python packaging/build_report.py`。保存构建日志和 Nuitka compilation-report.xml。
5. 对最终客户包重新执行内容审计、哈希检查、DLL 加载与离线录包验证。本次没有生成新发布包，旧包不应标记为本次验收通过。
6. 目标机解压整个客户文件夹到可写的本地目录，例如 `C:\LidarTool`；保留 web、plugins、corrections 和同目录运行库。不要单独复制 EXE。
7. 按授权说明获取目标机机器码并签发对应许可证；PD 许可证不可替代物理机许可证。发码工具和私钥不随客户包分发。
8. 安装适合目标机的 Npcap；启动时允许管理员权限。浏览器打开 `http://127.0.0.1:17777`，确认五个解码器加载、抓包模式与网卡状态。无 Npcap 时 UDP 降级不能等价替代二层发现和 VLAN 自适应。

# 砺见智行工作室激光雷达测试工具

本版在原 UniversalLidarViewer 中集成报告模块，只有一个程序。双击“砺见智行工作室激光雷达测试工具.exe”并允许 Windows 管理员权限，打开原点云查看器，无需安装 Python。管理员权限用于临时设置雷达网卡 IP/VLAN并在退出时恢复。

## 使用步骤

1. 连接雷达或在原查看器导入 PCAP，确认点云显示正常。
2. 点击顶部“检测报告”。报告在当前窗口内打开，底层点云连接继续工作。
3. 程序先从点云数据流识别雷达 IP、物理网卡和 VLAN；需要时保存原网卡配置，再临时设置同网段 IP/VLAN。报告自动使用识别出的 IP，优先通过设备网页接口带入参数；网页不可达时才尝试兼容型号的 PTC。多台设备时选择目标设备。Pandar40P 可从网页读取型号、SN、生产日期、版本、运行统计、网络配置和转速；电压、电流只有设备实际返回时才填写。
4. 品牌、型号、IP、端口、部分网络参数、查看器版本、SDK插件状态和软件队列统计自动填入相应记录。提供的数据取决于当前查看器和雷达实际返回值；自动采集不会把检测项目自动判为正常或合格。

重复执行设备读取、PTC采集或点云三视图采集时，同一来源的自动记录会更新为最新数据，不会在报告中重复追加；手工填写的检测记录会保留。
5. 点击“自动采集点云三视图”，从当前同一帧点云生成斜视、侧视一、侧视二，恢复原相机角度，并填写点数和接收帧率。设备不一致或没有有效点云时不会写入截图。
6. 在“外观”中选择六张图片，视角保留“普通图片”。九宫格前六格自动放入外观图片，后三格使用点云三视图。三视图也可手工上传并指定视角。
7. 点击“生成报告”预览，下载 PDF 或 PNG。多页PNG自动打包ZIP，PDF、PNG、HTML均包含标注和水印。
8. “返回点云查看器”继续观察点云；再次打开报告时当前草稿仍保留。关闭整个程序前务必保存草稿文件，然后点击“安全退出并恢复网卡”。直接关闭最后一个查看器页面也会自动退出并恢复。

## 图片与报告

每个检测项都可上传JPG、PNG、WebP，每张最大15MB，导入后最长边缩放到1800像素，原文件不变。点击“标注”输入文字并拖动框选，可撤销上一处。自动采集的点云图也可标注。

图片可前移/后移调整顺序，多余外观照片按每页九张继续排版。缺图保留占位，按原比例排版，不裁切边缘。

报告采用红色标题栏、白底中英双语表格和勾选式检验结果，页脚署名“砺见智行工作室”。可自定义水印文字、透明度和角度；文字留空关闭水印。“我司采购日期”已删除，旧草稿导入时自动移除。

SDK插件丢包/丢帧统计是软件队列全局计数，不等于单台雷达的网络丢包率；接收帧率不等于机械转速。SN、生产日期和软硬件版本以目标雷达实际返回为准；未返回的字段以及维修履历、质保等信息需人工补充。评分与判定由检测人员填写，四项分数全部填写后自动求和，等级按你的评估标准填写。

程序启动时申请管理员权限。修改网卡前会在应用配置目录写入 `network-recovery.json`，其中记录原 IPv4、DHCP、VLAN ID 和优先级/VLAN开关。正常退出时自动恢复并删除日志；强制结束后，下次启动先根据日志恢复。不要在程序运行期间手工修改同一块网卡，否则恢复时会以程序启动前保存的状态为准。

“保存草稿”下载包含图片、标注、资料和水印的JSON文件。“打开草稿”可继续编辑旧报告。浏览器关闭后不会自动保留未保存的工作。PDF采用整页图像以保持导出一致，文字不可单独选择。

## 源码构建

仍从原入口启动：python run.py。构建融合版：python packaging/build_report.py。

构建将原查看器、报告页面、厂商解码插件和修正文件一起嵌入EXE，不包含授权私钥或测试用模拟点云。

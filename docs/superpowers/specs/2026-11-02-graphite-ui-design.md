# 砺见智行桌面工具：石墨黑与冰蓝界面设计

状态：视觉方向已选定，待用户确认具体设计。

## 目标

把现有 C++17 / Dear ImGui / GLFW 应用整理成精致、克制的专业点云工作台。用户已选择石墨黑与冰蓝方向，并要求 Windows、macOS 界面一致。继续使用原生技术栈，保留 PCAP、实时监听、渲染、网络、PTP、型号支持及检测报告的功能入口和现有业务行为。

## 方案比较

- 石墨黑＋冰蓝：低饱和层级背景、清晰信息密度、蓝色用于选中和主要操作。用户已选择此方案。
- 深灰＋品牌红：延续原有工业风，改动较小，但大面积红色容易与告警混淆。
- 浅灰＋深蓝：适合明亮环境，但改变现有暗色点云观察体验。

## 具体设计

### 工作区

保留顶部导航、左侧设备与数据源、中央三维点云、右侧属性控制的结构。采用 8px 间距基准，面板内边距 16px，控件圆角 6px，面板圆角 8px；采用细边框、实色背景，不添加模糊、发光或装饰动画。

默认 1600×960 下顶部约 72px、左侧约 264px、右侧约 320px。实现者可在视觉验证时微调这些数值。导航与指标不得重叠；较窄窗口时指标可移动到独立状态区，次要说明换行，长列表与属性面板允许滚动。目标最小工作区 1100×720 个逻辑像素，窗口尺寸约束与高 DPI 缩放应相互匹配。

顶部左侧保留品牌文字与简洁的雷达图形，移除标题内给用户无帮助的技术实现字样。中部导航采用深色底与浅蓝文字/细线表达选中态；右侧展示点数、帧率与状态。空闲、回放、实时状态同时使用文字与颜色，不以颜色单独表达。

左侧以设备概览、输入来源、系统日志分区。端口标签自动排布，日志有独立滚动区域，避免底部固定坐标覆盖设备内容。中央保留点云主视野，使用低调的状态浮层、底部操作提示；空闲时清楚提示导入 PCAP 或配置实时监听，不显示 LIVE。右侧按显示、视角、回放等分组，常规按钮使用中性底，仅主要操作用冰蓝。网络、PTP 和支持型号页面共享同一视觉语言。

检测报告工作台沿用现有目录与表单流程，统一标题、分组、输入框、操作按钮和状态提示。报告导出的 HTML/PDF 内容与纸张设计不在本次改造范围。

### 配色与字体

- 三维背景 `#0C1118`，面板 `#151C26`，抬升表面 `#1C2633`，输入区域 `#111923`。
- 边框 `#2A3747`；正文 `#E8EEF7`，次要文字 `#9BAEC3`。
- 强调冰蓝 `#74B9FF`，主要按钮使用足够深的蓝底配浅色文字，并验证正文与按钮文字对比度至少 4.5:1。
- 成功绿色、等待琥珀色、错误红色仅表达语义；保留图形标识的品牌识别，避免红色大面积导航。
- 两端随应用打包同一份允许再分发的中文字体（优先 Noto Sans SC，附许可），同字号和字形范围；系统字体只作为资源缺失时的兜底。字体定位相对于可执行文件或应用资源目录，不依赖启动工作目录。
- 常规正文约 16 个逻辑像素，次要文字不通过极低对比度弱化。高 DPI 下保持文字清晰、点击区域与绘制比例匹配。

现有工作区有大量未提交文件，本次只调整相关文件，不覆盖其他改动，不为提交设计文档而把现有应用目录或业务改动一并提交。设计文档先保存在工作区，提交留待实现完成后按用户意愿处理。

跨平台一致指应用内容区的配色、字体、尺寸和布局规则一致；标题栏、系统文件选择器沿用平台行为。当前主机为 macOS，需分别构建 macOS 与 Windows；Windows 若无可用运行环境，明确说明仅完成交叉编译，不能声称完成 Windows 真机视觉验收。

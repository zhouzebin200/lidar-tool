# E2 网页查看器接入

用户范围：仅网页查看器，不改 ROS。基线：GitHub main 34abaaa。

采用现有 RoboSense 插件内独立 E2 解码模块：Python 按 844 字节 MSOP 和 1296 字节标定包识别 RSE2，C++ 将数据转换到既有 ABI v2 点云回调，沿用 PCAP、在线接收与 WebGL 显示。

方案比较：整包升级 SDK 会替换现有型号接口；另建 ROS 转发不符合用户需求；插件内接入只增加 E2 所需协议、默认方向表和标定 CRC，保持原型号路径。

SDK 来源为用户提供 rslidar-ros-sdk.zip，SHA256 2251cbddfe364f5d5acb42bed0f2f5224c8fe217cc5e27366444e3ecac2ffdd5。默认表为名义标定，设备下发完整且 CRC 有效的 360 包标定后替换。保留双回波，过滤零距离/零方向，拒绝越界块和错误标定。MSOP CRC 未在厂家解码器中校验，不擅自增加未经实测验证的拒收条件。

验证：合成协议包、厂家默认表数值、完整/损坏/缺包标定、帧切换、双回波、插件 ABI 到浏览器二进制协议，以及现有 Python 回归。无 E2 实机抓包，不宣称实机已验证。

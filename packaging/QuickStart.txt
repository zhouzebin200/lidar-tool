Universal LiDAR Viewer Windows 便携版
====================================

1. 双击 UniversalLidarViewer.exe。
2. 程序会自动打开浏览器，默认地址：http://127.0.0.1:17777
3. 关闭该程序打开的最后一个网页后，后台服务会自动退出并释放端口。
4. 也可以在网页右侧点击“导入 PCAP”离线回放抓包文件。

本 EXE 已内置：
- Python 运行时和网页界面
- Hesai SDK 2.0 解码插件
- RoboSense rs_driver 解码插件
- Velodyne 原始 UDP 点云解码插件（不包含 ROS/PCL）
- AT128 和 Velodyne 默认修正文件

说明：
- 无需安装 Python，也无需复制 SDK、plugins、web 或 corrections 文件夹。
- 普通 UDP 手动监听不依赖 Npcap。
- 自动发现任意端口、VLAN 和跨网段 ARP 引导需要 Windows 安装 Npcap。
- Windows 首次运行未知发布者程序时，SmartScreen 可能要求选择“更多信息”后运行。
